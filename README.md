## 🛠️ Tech Stack

### Frontend
- **HTML5** – Semantic markup with accessibility features
- **CSS3** – Custom properties, flexbox, grid, animations
- **JavaScript (Vanilla)** – No frameworks, pure DOM manipulation
- **Bootstrap 5** – Grid system and components
- **Font Awesome 6** – Icons
- **Google Fonts** – Inter & JetBrains Mono
- **Server-Sent Events (SSE)** – Real-time streaming updates

### Backend
- **Python 3** – Core application logic
- **Flask** – Lightweight web framework
- **Requests** – HTTP client for API interactions
- **Mail.tm API** – Temporary email generation
- **Firebase Authentication API** – User registration & verification
- **Builder.io Signup API** – Final account creation
